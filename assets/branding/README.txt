CAPTURE — Windows icon kit

CAPTURE.ico  Multi-resolution Windows icon (16, 24, 32, 48, 64, 128, 256 px)
CAPTURE-icon-master.png  Original 1254×1254 transparent artwork
AppList.targetsize-*.png  Windows target-size icons in default, dark, light forms

For a conventional Windows desktop .exe use CAPTURE.ico as the app icon.
For an MSIX/packaged Windows app, use the target-size PNG assets and follow
Microsoft's icon construction guide and your app's packaging conventions:
https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-construction

The three target-size variants currently use the same artwork, which has
opaque light/dark forms intended for use on both themes. Test against both
light and dark taskbar backgrounds before shipping.
