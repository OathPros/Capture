# Current milestone
Windows capture preview with the requested DOCX, Markdown and HTML exports. Full V1 and interactive M1 capture acceptance remain incomplete.

## Implemented
- Existing WPF/WebView2 shell, tray, configurable hotkey, consent, recording controls, bounded mouse queue, UIA worker and two-frame prototype GDI capture buffer.
- Existing local guide persistence/recovery, text and highlight editor, undo/reorder, serialized autosave, and validated portable package import/export.
- Shared export-only PNG rendering validates image paths, dimensions and checksums, flattens highlights, and leaves source images unchanged.
- Word DOCX export via Open XML SDK 3.5.1: title/introduction, ordered headings, instructions/notes, accessible embedded images with proportional page sizing, heading/paragraph grouping, Letter layout and page-number footer. No Office installation needed.
- Markdown ZIP with README.md and complete image assets, notes, escaped content, ordered steps and no unused project images.
- Self-contained HTML export: styled responsive guide, table of contents, numbered cards, notes, base64 screenshots, print styles and restrictive CSP; no script or external dependencies.
- Export buttons flush current edits, use native save/overwrite confirmation, render off the UI thread and replace existing outputs only after a successful complete write.
- Synthetic document examples generated by tests and packaged separately for release review.

## Verified locally
- Full solution cross-build (including Windows image tests): zero warnings/errors.
- Core suite: 28 passed, including DOCX Open XML schema validation, image relationships/size/aspect/alt text, multilingual and long content, Markdown link/asset completeness, offline HTML escaping/CSP, text-only guides and missing-image failures.
- Editor unit suite: 2 passed. Browser suite: 3 passed, covering native export command formats, save-before-export and standalone HTML desktop/mobile behavior.
- Generated DOCX opened and rendered by LibreOffice to Letter-size pages. HTML visually inspected at desktop/mobile sizes; images decoded, no horizontal overflow, no external requests.
- GitHub Actions Windows export release run 41195294077 passed: 28 core tests, 4 actual Windows image-rendering tests, 2 editor unit tests and 3 browser tests (37 total), build and packaging. Release v0.2.0-preview.1 includes the Windows app and sample exports.

## Windows checks
The new Windows test project exercises actual GDI PNG rendering through DOCX, Markdown and HTML, checks red highlight pixels/unchanged originals, and rejects changed source checksums. It compiles on Linux and all four tests passed on Windows in release run 41195294077. scripts/test.ps1 and GitHub Actions run it on Windows.

Interactive capture, hotkeys, UIA, protected surfaces, timing/mixed DPI, native save dialogs and full packaged-app startup still need the manual Windows matrix. Automated document/pixel tests do not establish those outcomes.
