Get started

Up and running in three steps.

  1. Download the installer

    Save the YU Capture Setup file, then open it from your browser’s downloads.

  2. Follow the setup wizard

    Choose Install. Setup keeps all files together and installs Microsoft WebView2 if needed. No .NET download is required.

  3. Launch and capture

    Choose Launch at the end of setup, or open YU Capture from the Windows Start menu.

Requires Windows 11 x64. Setup needs internet access if Microsoft WebView2 is missing. To update, exit Capture from the tray and run the new installer. Uninstall from Windows Settings → Apps; saved projects are preserved.
